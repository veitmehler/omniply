# X-Ray Outreach — LinkedIn + Cold Email (Copy Master)

**Status: DRAFT v1 for review — 2026-08-05**

Warm-ish outreach to first-degree LinkedIn chiro connections + low-volume cold
email. ONE job: get them to run the Practice X-Ray. The moment they engage,
outreach ends and the funnel (quiz → report → nurture) takes over.

## Rules of engagement

- **LinkedIn is primary.** Hand-sent, 15–20 DMs/day max, no automation tools
  (account risk). Personalize the first line where it's effortless (city,
  something from their profile) — never fake familiarity.
- **Cold email is secondary** and NEVER from the nurture/product domain.
  Dedicated lookalike domain (e.g. getomniply.com), own mailbox, SPF/DKIM/DMARC,
  ~2 weeks warm-up, then 10–20/day. Plain text, no HTML template, no images —
  cold email should look typed, because it is.
- **Handoff rule:** any reply or quiz completion → stop the sequence. Replies
  get a human answer from Veit, not a template.
- **Exit with grace:** these are connections and colleagues-of-colleagues. Three
  touches, then done. The relationship outlives the campaign.
- Personalization slots: {{first_name}}, {{practice}} (only when known — never
  guess), optional {{city}}.

> calls a week go unanswered, four system scores, and a dollar figure on

*(The question earns the reply, makes the link requested instead of pushed,

## Playbook

1. **Prep**: export/list your chiro connections; one row each: name, practice,
   city, email-if-known. Work top-down by warmth (people who'd recognize you
   first).
2. **Daily**: 15–20 LinkedIn Touch-1s. Log sends + dates (sheet is fine).
   Cold email runs the same list's email-known subset, offset so nobody gets
   both channels on the same day.
3. **Cadence**: LinkedIn 0 / 5 / 10. Email 0 / 4 / 9. Reply anywhere → stop
   everything, talk like a person.
4. **Measure weekly**: sends → replies → X-Rays run (GHL shows quiz
   completions; match names) → walkthrough views. Adjust Touch 1 wording, not
   the structure, if replies are thin.
5. **Never**: bulk-blast the whole list in a day, use automation on LinkedIn,
   send cold from the nurture domain, or follow up past touch 3.
